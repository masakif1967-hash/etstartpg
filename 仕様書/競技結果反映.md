#　競技の結果を共有ファイルに反映
## 前提：競技の結果を保存のタイミング
下記いずれかの場合を「競技の結果を保存のタイミング」とする。
- ［保存］ボタン押下
- ［リセット］ボタン押下
- 「Go to the Start 操作」終了
## 競技の結果を保存のタイミングで「result.json」ファイルにリザルトポイントを反映する。
既存の「result.json」ファイル内のteams.TeamNameが操作用ウィンドウのチーム名と一致するフォルダ内の既存の下記フィールドにリザルトポイントを設定する。
- LorRのラジオボタンの設定がLの場合、teams.gameL_score 
- LorRのラジオボタンの設定がRの場合、teams.gameR_score
