# Go to the start
	- ファイル名：starting.py
	- クラス名:Stating

# 仕様
起動すると、操作用ウィンドウと表示用ウィンドウの2枚が表示される。
「./音声データ/ETロボコン120秒（スタート合図から120秒タイムアップ）.mp4」を再生開始。
## 画面イメージ
「Go to the Start」
- 操作用ウィンドウ
	|項目|種別|備考|
	|:--|:--|:--|
	|カウントダウン時間（秒）|テキストボックス|設定可能範囲0～120（default:120）|
	|スタート|button|ボタン押下で「./音声データ/ETロボコン120秒（スタート合図から120秒タイムアップ）.mp4」を再生開始。|
	|リセット|button|タイマーを止め、押下でカウントダウン時間をdefault値に戻し、スタートボタン押下されるまで待機する|
	|音量|スライダー|mp4の再生音量調節|

- 表示用ウィンドウ
	- デフォルト背景色黒、文字色白
	- カウントアップタイマーの経過時間（0.1秒）を表示
	- 残り時間が10.0秒以下になれば文字色黄色
	- 残り時間が0.0になれば停止背景色赤
	- ウィンドウサイズに合わせたフォントサイズの表示。画面横幅サイズの80%程度。

- 音声が「Go to the Start Go」の最後の「Go」を合図にカウントアップを開始する。
- 120秒経過したらタイマーを止める。
