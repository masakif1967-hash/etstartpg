# 結果発表画面を作成します。
- ソースファイル名: result.py

## 仕様
1. 起動と共に「result.json」ファイルを読み込む
2. チーム毎にスコアを計算する
	1. game_score_av = （gameL_score + gameR_score）/ 2.0
	2. game_score =  game_score_av / 73.0 * 100
	3. model_scoreを7、game_scoreを3の割合で調和平均を求める
	4. この調和平均で求めた値がこのチームの総合成績とする。
3. game順位として game_score_av の大きいチームから　順位、チーム名、gameL_score、gameR_score、game_score_avの順で1行筒コンソールに表示
4. 総合順位として 総合成績の大きいチームから　順位、チーム名、model_score、game_score、総合成績の順で1行ずつコンソールに表示
